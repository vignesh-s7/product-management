Quickstart — 3 Steps to Your First PO Session

We provide skills only. Your local AI agent does discovery, PRD writing, gate checks, and POC/MVP artifacts. No vendor runtime, no API keys, no account with us.

Step 1

Clone the repo

Skills are already mirrored in .cursor/skills/ on clone. For Claude Code, see .claude/skills/.

git clone https://github.com/vignesh-s7/product-management.git
cd product-management

Core personas: productowner-skill, PO-discovery, PO-delivery, cybersec-skill, y-score-readiness, and more.

Step 2

Edit .agent/memory.md

Every skill reads memory first. Customize product_name, domain, compliance_regimes, and constraints for your product.

mkdir -p .agent artifacts
touch artifacts/.gitkeep
Step 3

Tell your agent to run discovery

Open Cursor, Claude Code, or Antigravity and say:

Act as Product Owner — run discovery for [your problem statement]

Your agent reads memory, loads skills, runs the persona swarm, and writes outputs to artifacts/ in your repo.
