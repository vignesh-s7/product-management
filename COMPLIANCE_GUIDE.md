# Enterprise Compliance & Responsible AI Guide

**productowner-skill** is designed from the ground up to be a **Responsible AI** plugin that inherently aligns with, rather than circumvents, strict Enterprise IT and Cybersecurity policies. 

By operating entirely as a declarative, stateless Markdown Swarm, it guarantees compliance with the highest standards of Data Sovereignty and Privacy.

## 1. Data Minimization & Synthetic Data Mandate
To ensure strict alignment with **GDPR, CCPA, and Enterprise IP protection policies**, this plugin enforces a "Data Minimization" protocol. 
* **The Rule:** The `productowner-skill` and `ux-pro-skill` are explicitly instructed to reject the processing of real Personally Identifiable Information (PII) or Protected Health Information (PHI).
* **The Workflow:** Users are prompted to use generic placeholders (e.g., "Project Alpha", "Vendor X") when generating architectures and PRDs. This ensures that the outputs generated by the AI naturally comply with enterprise Data Loss Prevention (DLP) keyword scanners and respect corporate confidentiality.

## 2. Zero-Telemetry & Data Sovereignty
Many AI tools rely on outbound API calls, telemetry tracking, or background analytics that violate corporate proxy rules (e.g., Zscaler) and SOC2 policies.
* **The Rule:** This plugin suite is 100% Markdown text. It contains absolutely zero executable code, network requests, or telemetry trackers.
* **The Workflow:** It operates entirely within the boundaries of the user's *existing, IT-approved* local AI agent (such as Antigravity). Because the plugin relies on the host agent's secure tunnel, it guarantees that no data is exfiltrated to unauthorized third-party servers. 

## 3. Supply Chain Security (Zero Dependency SBOM)
Enterprise security teams are increasingly concerned about Software Supply Chain attacks (e.g., malicious NPM packages or vulnerable Python dependencies).
* **The Rule:** Our Software Bill of Materials (SBOM) is effectively zero. 
* **The Workflow:** Because the plugin is completely devoid of external libraries, package managers, or Docker images, it eliminates the risk of supply chain vulnerabilities, making it immediately safe for deployment in locked-down Virtual Desktop Infrastructure (VDI) environments.

## 4. Responsible Output Management
Rather than attempting to push data out of the corporate network (which violates Air-Gap policies), the plugin is designed to write its outputs (PRDs, FSDs, UI components) directly to the local file system. 
* This allows the enterprise's existing EDR (Endpoint Detection and Response) and DLP tools full visibility and control over the generated artifacts, ensuring that IT retains ultimate governance over the AI's output.
